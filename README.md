# My Sindbad

مساعدك الذكي للسفر باللغة العربية. التطبيق يعمل كتطبيق ويب تقدمي (PWA) ويمكن تثبيته على الهاتف أو الحاسوب.

## التشغيل

```bash
npm start
```

## الخدمات الحقيقية

- البحث عن المدن والوجهات والأماكن يتم عبر OpenStreetMap وOverpass.
- حالة الطقس الحية تأتي من Open-Meteo.
- أسعار الصرف تأتي من Frankfurter.
- خطط الرحلات وقائمة التجهيزات تحفظ محلياً على جهاز المستخدم، ولا يتم تقديم بيانات فنادق أو مطاعم ثابتة عند فشل الخدمات الخارجية.

يحتاج الخادم إلى Node.js 18 أو أحدث، ويمكن تشغيله عبر:

```bash
npm start
```
