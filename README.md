# نظام جمعية إحمدا للماء الصالح للشرب

نظام عربي باتجاه RTL لتسيير المشتركين والعدادات والقراءات والفواتير والتحصيل والمصاريف والموارد البشرية.

## التشغيل

```bash
npm start
```

يستعمل الخادم المتغير `PORT` عند توفره. البيانات التجريبية تحفظ محلياً في المتصفح عبر `localStorage`.

## الدخول التجريبي

- اسم المستخدم: `admin`
- كلمة المرور: `123456`

كما توجد حسابات `agent` و`treasurer` بنفس كلمة المرور، مع صلاحيات مختلفة.

## النشر

الواجهة ثابتة داخل `public/index.html`، ويمكن تشغيلها على GitHub Pages عبر سير عمل GitHub Actions المرفق.
