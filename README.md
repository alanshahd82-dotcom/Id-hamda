# نظام جمعية إدحمدا للماء الصالح للشرب

نظام عربي RTL لإدارة المشتركين والعدادات والقراءات والفواتير والتحصيل والمصاريف والموارد البشرية والتقارير لجمعية إدحمدا للتنمية والتواصل والماء الصالح للشرب.

## التشغيل

```bash
npm install
npm start
```

يستعمل الخادم المتغير `PORT` عند توفره، ويستعمل `SESSION_SECRET` لجلسات الدخول. يتم إنشاء `db.json` تلقائيا عند التشغيل الأول، وتُحفظ فيه كل التغييرات.

## الدخول التجريبي

- اسم المستخدم: `admin`
- كلمة المرور: `123456`

كما توجد حسابات تجريبية بصلاحيات `agent` و`treasurer` بنفس كلمة المرور.

## الوحدات

- لوحة الأداء والإحصائيات حسب السنة
- المشتركين والمراكز والعدادات والحالات
- التسعيرة والواجب الثابت والغرامات
- القراءات مع كشف الاستهلاك الشاذ والحفظ الجماعي
- توليد الفواتير وطباعة فاتورة A4
- الاستخلاص بالفواتير المتعددة ووصل الأداء والطباعة
- المصاريف والموارد البشرية
- التقارير المالية والشهرية وتقارير الدفعات والمشتركين والاستهلاك والموظفين
- الإعدادات العامة وشروط الاستخدام وقوالب طلب الاشتراك والالتزام وتأشيرة الدين
